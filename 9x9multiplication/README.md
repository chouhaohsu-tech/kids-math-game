# 🌈 Ning's 9×9 Non-Repeating Multiplication Adventure (動物回家九九乘法表)

An interactive, bilingual (**English & 繁體中文**) math adventure web application created for **Ning** to learn the **9×9 Non-Repeating Multiplication Table** based on the upper-right triangle L-path pedagogy.

---

## ✨ Key Features

1. **📐 Upper-Right Triangle Non-Repeating Board:**
   - Displays the 45 non-repeating multiplication facts ($r \le c$) in the exact rainbow column palette from the reference chart.
   - **Pre-Filled Diagonal Square Numbers ($1, 4, 9, 16, 25, 36, 49, 64, 81$):** Highlighted in dashed boxes as the special "Corner Stones" where each animal turns right toward its home.
   - **36 Interactive Blank Boxes:** Ready for Ning to fill in using the musical on-screen keypad or physical keyboard.

2. **🐾 "Take Every Animal Home" L-Path Story:**
   - **9 Animal Friends:** 🐼 Panda (1), 🐰 Bunny (2), 🐶 Puppy (3), 🐸 Froggy (4), 🐵 Monkey (5), 🐱 Kitty (6), 🐧 Penguin (7), 🐥 Chick (8), and 🐷 Piggy (9).
   - Each animal starts at the **top of Column $N$**, hops down Column $N$ to the **Square Number Corner $(N \times N)$**, turns right across **Row $N$**, and arrives at its **Home** at the end of Row $N$!
   - Every correct answer triggers a celebratory jump animation, confetti burst, glockenspiel chime, and spoken praise (including Traditional Chinese 九九乘法口訣 or English voice).

3. **🎮 Two Rich Interactive Game Modes:**
   - **🏡 Story Mode:** Guides Ning step-by-step along each animal's L-path (with visual grouping hints like `2 groups of 3 = 3 + 3` and the animated Teacher Cat).
   - **🔍 Clue Mode (Minesweeper-Style Clue Sweeper):**
     - Starts with a few pre-revealed numbers on the triangle map (plus the 9 diagonal square anchors).
     - Kids inspect the revealed numbers to deduce adjacent hidden mystery tiles using skip-counting arithmetic clues ($+r$, $-r$, $+c$, $-c$).
     - Each correctly solved tile flips open with an exciting pop, instantly creating **brand new clues** for its surrounding neighbors!
     - Step-by-step chain-reaction unlocks the entire 36-tile multiplication map, just like uncovering safe tiles in Minesweeper!
     - Includes 3 difficulty levels: 🟢 Easy (12 Seeds), 🟡 Medium (6 Seeds), 🔴 Hard (2 Seeds / Master Sweeper) and a `🔄 New Map` random generator.

4. **📱 Tailored for iPad & Tablets:**
   - Optimized landscape screen-fitting for iPad (e.g. 1024×768, 1080×810, 1180×820, 1194×834) with zero wasted empty space, large kid-friendly touch targets (52px–62px), and clean view management.

5. **🌐 Bilingual Toggle (EN / 繁體中文):**
   - Switch between English and Traditional Chinese UI, hints, and voice synthesis at any time with one click.
